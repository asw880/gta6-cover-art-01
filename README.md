Vice City Cover Studio — an offline web app that turns your photos and a caption into GTA-style multi-panel cover art: a painted Vice City sunset sky, six slash-and-grid layouts, five neon grades, one-click Looks, stacked display lettering, and one-click PNG export in 1080×1080, 1080×1350 and 1920×1080. Photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. To build the dossier:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
