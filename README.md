Vice City Cover Studio — turn your photos into a GTA-style multi-panel poster. A painted sunset sky (slatted sun, horizon glow) sits behind six panel layouts, five colour grades, and one-click Looks presets; a stacked display title, badge ribbon and star meter finish the cover. Upload up to four photos or use the samples, click a panel to select it, drag to reposition, and export the PNG in 1080×1080, 1080×1350 or 1920×1080. Offline, no libraries, no network requests. Fonts are Anton and Pacifico under the SIL Open Font License.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
